# Contributing to B4Thinkin'

Thanks for wanting to help! B4Thinkin' is a free study platform for students, and every improvement helps.

## Ways to contribute

- Report bugs
- Suggest features or study content
- Fix typos or improve the docs
- Improve design, accessibility or performance

## Getting started

1. Fork this repository
2. Clone your fork: `git clone https://github.com/<your-username>/<repo-name>.git`
3. Create a branch: `git checkout -b my-change`
4. Make your changes and test them in a browser (open `index.html`; for the admin page open `admin.html`)
5. Commit with a clear message: `git commit -m "Fix chat scroll on mobile"`
6. Push and open a Pull Request

## Guidelines

- Keep changes focused: one fix or feature per pull request
- Match the existing code style
- Test on mobile as well as desktop; most students use phones
- **Never commit secrets** such as passwords, Supabase service keys or private tokens. Only public (anon) keys belong in client code
- Be respectful, see the [Code of Conduct](CODE_OF_CONDUCT.md)

## Reporting bugs

Use the **Bug report** issue template and include steps to reproduce, what you expected, what happened, and your device/browser.

## Security issues

Please do not open public issues for vulnerabilities. See [SECURITY.md](SECURITY.md).
