# Accessibility Statement

B4Thinkin' aims to be usable by every student, including people with disabilities.

## Commitment

We work towards meeting WCAG 2.1 Level AA where practical: readable text and contrast, keyboard-friendly controls, clear labels, and layouts that work on small screens.

## Supported environments

- Modern mobile browsers (Chrome, Safari, Firefox, Edge) on Android and iOS
- Modern desktop browsers
- Common screen readers (TalkBack, VoiceOver, NVDA)

## Known limitations

- Some interactive parts (such as the live chat) may not be fully optimised for screen readers yet
- Third-party content may have its own accessibility issues

## Reporting barriers

If you hit an accessibility problem, please open an issue using the **Bug report** template and mention "accessibility", or contact the maintainer (Amshar) via the GitHub profile. We'll do our best to fix it.
